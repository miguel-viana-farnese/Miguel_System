# Miguel System (PT)

Um sistema de Ponto de Venda (PDV) simples, leve e eficiente desenvolvido em Python, focado em pequenas empresas e comerciantes.

- **Linguagem:** Python 3
- **Interface Gráfica:** Tkinter / ttk
- **Banco de Dados:** SQLite3

## Como Executar

1. Vá até a aba Releases deste repositório.
2. Baixe a versão mais recente.
3. Coloque o arquivo `Miguel_System` dentro de uma pasta e execute.
*(Nota: lembre-se de dar permissão de execução.)*

# Miguel System (EN)

A simple, lightweight, and efficient Point of Sale (POS) system developed in Python, designed for small businesses and merchants.

- **Language:** Python 3
- **Graphical Interface:** Tkinter / ttk
- **Database:** SQLite3

## How to Run

1. Go to the Releases tab of this repository.
2. Download the latest version.
3. Place the `Miguel_System` file in a folder and run it.
*(Note: remember to grant execution permissions.)*
